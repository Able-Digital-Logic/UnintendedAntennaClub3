What the interface preserves

  • Carrier, pulse description, DUT and cable identities
  • Raw-code mode versus filtered/decimated mode
  • Trigger markers, clipping and explicit data gaps
  • Calibration identity and operating validity

Calibration needs external reference measurements. This prototype collects no calibration data and never activates simulated coefficients.

Design target: native 1 Mpaired samples/s, with separate display updates and an SD write buffer. Sampling performance, card latency, cable loading and calibration still require hardware qualification.
